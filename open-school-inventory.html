Lab Info

Admin PIN

Default PIN is 1234. Change it now. With the server, the PIN is checked by api.php and never sent to student devices.

Categories

Renaming a category here does not change items already using the old name — edit those items or re-import them.

Inventory Spreadsheet (CSV)

Fill in the template in Excel or Google Sheets, save as CSV, then import. Rows with an id that already exists update that item; rows without an id are added as new items.

Email Setup (EmailJS)

Free setup at emailjs.com. Steps: (1) Create account → (2) Add Email Service (Gmail works) → (3) Create Template with variables {{to_email}}, {{subject}}, {{message}} → (4) Copy your Public Key, Service ID, and Template ID below.
Student emails are built automatically: studentid@domain — e.g. 123456@school.edu. Students receive a confirmation on checkout and a receipt on return.

Data Backup & Restore

Export a full JSON backup regularly. Store it somewhere safe. If you change devices or browsers, import the backup to restore all data.

About

Open School Inventory System. Works as a single HTML file (data in this browser's localStorage) or with api.php on a server so every device shares the same data. Export backups regularly.

Students browse to your server on their phones, open this page, and use the Check Out tab. The in-app camera scanner needs HTTPS or localhost. On plain http://, print labels with QR Code Contains → Link and students scan with their normal phone camera, or use manual search / a USB scanner.
